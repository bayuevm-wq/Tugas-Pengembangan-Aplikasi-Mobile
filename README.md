## Tentang

Repository ini berisi kumpulan tugas praktikum mata kuliah **Pengembangan Aplikasi Mobile**.

Seluruh project dikembangkan menggunakan **Kotlin Multiplatform (KMP)** dan **Compose Multiplatform**,
yang memungkinkan pengembangan aplikasi lintas platform (Android & iOS) dengan satu codebase.

## Daftar Praktikum

| No | Folder | Judul | Deskripsi |
|----|--------|-------|-----------|
| 1 | [`Praktikum1`](./Praktikum1) | My First KMP App | Aplikasi pertama menggunakan KMP, menampilkan identitas mahasiswa |
| 2 | [`Praktikum2`](./Praktikum2) | News Feed Simulator | Simulasi news feed menggunakan Kotlin Coroutines & Flow |
| 3 | [`Praktikum3`](./Praktikum3) | My Profile App | Aplikasi profil dengan reusable composable & Material 3 |

## Teknologi

- Kotlin
- Kotlin Multiplatform (KMP)
- Compose Multiplatform
- Material 3
- Kotlin Coroutines & Flow
- Android Studio
- Gradle (Kotlin DSL)
